# ML4FS: Machine Learning with and for Fuzzy Sets

ML4FS brings together researchers working at the two-way interface between
machine learning and fuzzy set theory: fuzzy representations that improve
learning, robustness and interpretability, and machine-learning techniques
that construct, adapt, validate and compress fuzzy sets and fuzzy systems
from data.
